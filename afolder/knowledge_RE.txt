async sẽ bi đứng vv nếu k được xử lý bằng try catch

khi mà gọi 2 hoặc nhiều api không phụ thuộc dữ liệu vào nhau (riêng rẽ), nếu gọi riêng thì gây chậm vì chúng phải chờ nhau
cách đúng là bọc vào trong Promise.all() 
const [user, products] = await Promise.all([
  fetchUserProfile(),
  fetchProducts()
]);

các phần tử được khai báo trong mảng phân rã của RN, tuy nhiên nó sẽ bị hủy nếu 1 trong số nó bị lỗi
để lấy ra trạng thái của từng api thì dùng Promise.allSelected (kể cả có lỗi)

interceptors.response.use() nhận hai hàm callback:

onFullFiled : HTTP response thành công (mặc định status 2xx)
onRejected : HTTP response bị lỗi hoặc request thất bại


apiClient.interceptors.response.use(
  hàmXửLýThànhCông,
  hàmXửLýLỗi,
);

khi tạo 1 hàm promise thì ts cho 2 hàm 
resolve(value), hoàn thành với value
reject(error),  kết thúc với lỗi error

const promise = new Promise((resolve, reject) => {
    // Xử lý công việc bất đồng bộ
});
